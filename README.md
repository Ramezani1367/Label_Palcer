# چیدمان هوشمند لیبل

جایگزین وب اسکریپت InDesign. اندازه و جهت کاغذ را خودش تشخیص می‌دهد، لیبل‌ها را می‌چیند، و کراپ‌مارک وسط لیبل‌های چسبیده را حذف می‌کند. پوشه هم‌اندازه از اولین خانه خالی ادامه پیدا می‌کند. دستور صحافی قبل از کاغذ انتخاب می‌شود و همان دستور بیرون خط برش روی حاشیه برگ چاپ می‌شود.

فرمت‌ها: PNG، JPG، TIFF، WEBP، PDF، PSD.

## اجرا با پایتون

```bash
python app.py
```

بعد در مرورگر باز کنید: http://127.0.0.1:8080

## آیکون

آیکون برنامه یک برگ با کراپ‌مارک است. فایل منبع را خود اسکریپت می‌سازد؛ لازم نیست آیکون را جدا طراحی کنید، مگر اینکه بخواهید شکلش را عوض کنید.

```bash
python build_icon.py
```

این دستور این فایل‌ها را می‌نویسد:

- `assets/icon-256.png` تصویر منبع، ۲۵۶ پیکسل
- `assets/icon.ico` آیکون ویندوز در اندازه‌های ۱۶، ۲۴، ۳۲، ۴۸، ۶۴، ۱۲۸ و ۲۵۶. PyInstaller همین را داخل `LabelPlacer.exe` می‌گذارد.
- `static/favicon.ico` و `static/favicon.png` آیکون زبانهٔ مرورگر

اگر شکل را عوض کردید، `build_icon.py` را ویرایش کنید و دوباره اجرا کنید. در گیت‌هاب لازم نیست این کار را دستی بکنید: گردش‌کار ساخت، قبل از PyInstaller همین اسکریپت را اجرا می‌کند. فایل `label-placer.spec` با `icon="assets/icon.ico"` آیکون را به فایل اجرایی وصل می‌کند.

ویندوز آیکون تک‌اندازه را در نوار وظیفه تار نشان می‌دهد. برای همین ico چند اندازه دارد.

## ساخت فایل اجرایی ویندوز با گیت‌هاب

این پوشه را همان‌طور که هست در یک مخزن گیت‌هاب بگذارید. گیت‌هاب خودش `LabelPlacer.exe` را می‌سازد. روی کامپیوتر شما ویندوز یا پایتون لازم نیست.

1. در گیت‌هاب یک مخزن تازه و خالی بسازید. تیک «Add a README» را نزنید.
2. محتویات همین پوشه را آپلود کنید. پوشه `.github` باید همراه بقیه برود، وگرنه ساخت خودکار شروع نمی‌شود.
3. شاخهٔ پیش‌فرض را `main` بگذارید.
4. زبانهٔ **Actions** را باز کنید. اگر خواست، Actions را فعال کنید.
5. گردش‌کار «ساخت فایل اجرایی ویندوز» باید خودش شروع شود. اگر نشد، روی آن بزنید و **Run workflow** را بزنید.
6. وقتی ساخت سبز شد، پایین همان اجرا **Artifacts** را باز کنید و `LabelPlacer-Windows` را دانلود کنید.
7. فایل زیپ را باز کنید و `LabelPlacer.exe` را اجرا کنید. یک پنجرهٔ سیاه باز می‌ماند و مرورگر روی برنامه می‌آید. آن پنجره را نبندید؛ با بستنش برنامه هم بسته می‌شود.
8. کارهایی که می‌چینید در پوشهٔ `LabelPlacer-data` کنار همان فایل اجرایی ذخیره می‌شوند.

خروجی ماژولار است، نه یک فایل تکی. `LabelPlacer.exe` فقط برنامه را روشن می‌کند. بقیه کنارش جدا هستند:

- `modules/engine.py` منطق چیدمان. این فایل را عوض کنید تا محاسبهٔ کاغذ و کراپ‌مارک بدون ساخت دوباره عوض شود.
- `modules/app.py` مسیرهای وب.
- `static/` و `templates/` رابط. بعد از ذخیره، برنامه را یک بار ببندید و دوباره باز کنید.
- `assets/` آیکون.
- `_internal/` کتابخانه‌ها. این پوشه را پاک یا جابه‌جا نکنید.

جزئیات همین چیدمان داخل فایل `MODULES.txt` کنار exe هم هست.
